# ใกล้ฉัน — เว็บไซต์ค้นหาร้านค้า

## ทดลองใช้งาน
- เปิด `index.html` ผ่านเว็บโฮสต์ HTTPS เพื่อให้แผนที่และการขอตำแหน่งทำงานได้ดีที่สุด
- ต้องเชื่อมต่ออินเทอร์เน็ต
- ข้อมูลแผนที่ใช้ OpenStreetMap / Nominatim / Overpass API ซึ่งเป็นบริการภายนอกและอาจจำกัดการใช้งาน

## เผยแพร่ด้วย GitHub Pages จาก Android
1. เปิด https://github.com แล้วเข้าสู่ระบบ
2. สร้าง Public repository ชื่อ `klai-chan`
3. อัปโหลด `index.html` ไปที่ root ของ repository
4. เข้า Settings > Pages
5. เลือก Deploy from a branch, branch `main`, folder `/ (root)`, กด Save
6. รอ GitHub Pages สร้างลิงก์เว็บ แล้วเปิดทดสอบ

## ข้อจำกัดก่อนใช้งานเชิงธุรกิจ
- ฟอร์มสมัครร้านค้าและระบบรับชำระเงินยังไม่ได้เชื่อมต่อฐานข้อมูลหลังบ้าน
- ยังไม่มีระบบบัญชีร้านค้า, ตรวจสอบข้อมูล, แผงผู้ดูแล, ชำระเงิน หรือระบบขายโฆษณาอัตโนมัติ
- ก่อนเปิดให้คนจำนวนมากใช้ ควรตรวจข้อกำหนดการใช้ข้อมูล/แผนที่ของผู้ให้บริการ
